# Claim System (Spring Boot + Selenium + Allure)

## Features
- Create insurance claims
- REST API with Spring Boot
- UI testing with Selenium
- Test reporting with Allure

## Tests
- API tests (JUnit)
- UI tests (Selenium WebDriver)

## Allure Report
Run:
./gradlew test
./gradlew allureServe

## Tech Stack
- Java 17
- Spring Boot
- Selenium
- JUnit 5
- Allure

## Run Application
./gradlew bootRun
